Study Summary

This project models autonomous cube behavior in a Pygame loop. The strongest themes are data flow between steering functions, state mutation in velocity and position, collision-response rules, and lifecycle replacement via lifespan checks.

  • Data and state core: Cube dataclass fields like x, y, vx, vy, size, lifespan, and death.
  • Behavior core: find_neighbors, compare_neighbors, compute_flee_steering, and compute_chase_steering.
  • Update pipeline: apply_steering -> update_cube -> check_kill -> draw functions.
  • Complexity focus: neighbor scans and per-frame loops over all cubes.
